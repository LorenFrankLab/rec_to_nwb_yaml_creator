Workspace Shared Hardware ✦ Validation & Export

Proposed model: three tiers — dataset / animal / day

✦ = new. The only structural addition is a dataset-level "Shared Hardware" area. Everything else is a re-parenting of things that already exist, plus reference dropdowns instead of re-typed copies.

Why: recording systems, cameras, DIO event types and opto hardware are physically shared across animals in a rig. Today they're stored per animal and kept consistent by cross-animal "divergence" guards — the guards are the tell that the data wants to live one level up. Store once here; animals/days reference it. No divergence is even possible, and a fix (e.g. a camera calibration) propagates to every animal at once.
