Jump to any section freely. Per-tab status (✓ ⚠ ✗) shows what's left; "Validation & Export" names the count to fix. No forced order, no "locked" step — the same status model as the Animal tabs.

  • + One consistent model: Animal and Day are tabbed section-navs.
  • + Fix-one-field is a direct jump, not a back-step.
  • + Status lives on each tab; Export is a tab that says "2 to fix" instead of a locked gate.
  • − Loses the explicit "do these in order" hand-holding for a brand-new user.
  • ~ Mitigation: keep a "Next ▸" affordance on each tab for those who want the guided path.
Note: this is purely an interaction change — the steps, fields, validation, and export are identical. It's about whether the Day editor should feel like the Animal view (tabs, free navigation, per-section status) or stay a guided wizard. Lowest-risk version: adopt the tab shell + per-tab status, but keep an optional "Next ▸" button so the linear path still exists for new users.
